# contrib

`react-prototype-by-alco-uurimis.jsx` — исходник React-прототипа, который был закоммичен как `index.html` (коммит be68ed3, автор alco-uurimis). Как `index.html` он работать не может (это JSX, а не HTML), поэтому сайт использует статический `index.html` с `js/app.js`, а прототип сохранён здесь без изменений.

Не подключён к сайту. Внутри: тексты чтения, «эпизоды истории», грамматические модули и задания на письмо. Источники там указаны как «по материалам…»/«в стиле…» без ссылок и лицензий; прежде чем переносить эти тексты в `content/`, нужно подтвердить права на них и заполнить поле `source` (см. README, раздел «Источники и лицензии»).
